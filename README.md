# JG Mentor Demo Flow

## 데모 시연 흐름

### 1. 서비스 진입 및 인증

- `정글 AI 멘토` 서비스에 접속한다.
- 회원가입 화면에서 새 계정을 생성한 뒤 로그인한다.
- 로그인 후 상단 메뉴에 `게시판`, `AI 질문`, `지식베이스`, `내 활동` 탭이 표시되는 것을 확인한다.

### 2. 기본 게시판 기능 시연

- `게시판` 탭에서 게시글 목록, 검색창, 태그 필터, 인기 태그, 최근 댓글 영역을 확인한다.
- `글쓰기` 버튼을 눌러 제목, 내용, 태그를 입력하고 게시글을 등록한다.
- 등록된 게시글 상세 화면에서 작성자, 조회수, 태그, 본문이 표시되는 것을 확인한다.
- 댓글을 작성하고, 최근 댓글 영역에 반영되는지 확인한다.
- 본인이 작성한 게시글에 대해 수정과 삭제가 가능한 것을 보여준다.
- 목록으로 돌아가 검색어 또는 태그 필터를 사용해 게시글을 찾는 과정을 시연한다.

### 3. 게시글/댓글의 AI 지식베이스 반영 시연

- 방금 작성한 게시글과 댓글이 저장될 때 백엔드에서 AI 서버로 인덱싱 요청을 보내는 구조를 설명한다.
- 게시글은 `BOARD`, 댓글은 `COMMENT` 문서로 변환되어 Vector DB에 저장된다.
- 이 과정을 통해 사용자가 만든 게시판 데이터도 AI 답변의 근거 자료로 활용될 수 있음을 설명한다.

### 4. 지식베이스 화면 시연

- `지식베이스` 탭으로 이동한다.
- `블로그 검색`, `공식 자료`, `게시판 근거`, `댓글 근거` 카드의 문서 수를 확인한다.
- 각 카드의 `자료 보기`를 눌러 AI가 참고하는 실제 자료 목록을 보여준다.
- 외부 블로그, 공식 자료, 게시판 글, 댓글이 하나의 RAG 지식베이스로 통합되어 있음을 설명한다.

### 5. RAG 기반 AI 질문 시연

- `AI 질문` 탭으로 이동한다.
- 예시 질문을 입력한다.
  - `정글 알고리즘 학습을 어떻게 준비하면 좋을까?`
  - `내가 작성한 프로젝트 관련 글을 바탕으로 핵심 내용을 요약해줘`
- 답변 생성 후 화면에 `agentRoute`, `usedTools`, `참고 근거`가 함께 표시되는 것을 보여준다.
- AI가 단순히 LLM 지식만 사용한 것이 아니라, Vector DB에서 유사 문서를 검색한 뒤 근거 기반으로 답변했다는 점을 설명한다.

### 6. MCP 기반 GitHub 분석 시연

- `AI 질문` 화면에서 GitHub 저장소 URL이 포함된 질문을 입력한다.
  - `https://github.com/facebook/react 이 저장소의 기술 구조를 요약해줘`
- Agent가 질문을 GitHub 분석 요청으로 분류하고 `GITHUB_MCP_TOOL`을 사용하는 것을 보여준다.
- GitHub API를 통해 README, 주요 파일, 의존성 파일 등을 가져와 저장소 구조를 요약한다.
- 이 기능이 MCP 기반 외부 서비스 연동 기능에 해당하며, API Key는 환경변수로 관리된다고 설명한다.

### 7. AI Agent 추론 루프 시연

- 서로 다른 유형의 질문을 연속으로 입력한다.
  - 정글/학습 관련 질문
  - GitHub 저장소 분석 질문
  - 일반적인 개발 질문
- Agent가 질문 내용을 분류해 `RAG 검색`, `GitHub MCP 도구`, `일반 LLM 답변` 중 적절한 도구를 선택하는 흐름을 설명한다.
- 화면의 `agentRoute`와 `usedTools`를 통해 어떤 도구가 선택되었는지 확인한다.
- Guardrail을 통해 부적절하거나 민감한 입력은 차단하고, 무한 루프 없이 한 번의 요청 단위로 종료되도록 설계했음을 설명한다.

### 8. 마무리

- 이 프로젝트는 React 프론트엔드, NestJS 백엔드, PostgreSQL, FastAPI AI 서버로 구성되어 있다고 정리한다.
- 기본 게시판 CRUD와 댓글, 태그, 검색, 페이징을 구현했고, AI 기능으로는 RAG 기반 지식 검색, MCP 기반 GitHub 외부 연동, Agent 기반 도구 선택 흐름을 구현했다고 설명한다.
- 마지막으로 `내 활동` 탭에서 사용자의 작성 글과 AI 질문 활동을 확인하며 시연을 마무리한다.
