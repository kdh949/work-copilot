# Jira–Confluence Work Copilot Frontend

React + Vite 프론트엔드입니다.

## 실행

```bash
cp .env.example .env
npm install
npm run dev
```

기본 API 주소는 `http://localhost:3000`입니다.

## 화면

- 회원가입 / 로그인
- 회사 위키 문서 트리 조회
- 관리자 회사 위키 작성, 수정, 삭제
- 댓글 작성, 삭제
- 부서, 태그, 키워드 검색
- AI 챗봇 질문
- AI 답변을 새 노트로 저장
- AI 답변을 기존 노트에 추가
- 내 노트 작성, 수정, 삭제
